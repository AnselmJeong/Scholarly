# Scholarly 0.10.1

2026-11-14 · Native build 11

- Rust + GPUI Kit 앱과 기존 서재의 3단 UI를 제공한다.
- 학습용 설명 프롬프트, 스트리밍, 추출 캐시, 기존 노트 재작성·취소·이전 버전 복구를 지원한다.
- 원문 그림과 해당 그림을 인용하는 해설을 연결한다. 이미지 높이 오류와 수식 캐시 키 불일치를 수정했다.
- 한글 입력·메모 보존·본문 선택/복사·그림 연결 및 해제·좁은 창 배치를 검증했다.
- 창 구성별로 패널 폭을 보존하며, 설정에서 앱 버전을 확인할 수 있다.

빌드와 설치 방법은 [네이티브 안내](../../native/README.md), 실제 논문별 평가와 검증 범위는 [평가 기록](../evaluation/2026-11-13-learning-native.md)을 참조한다.

검증: 릴리즈 스냅샷의 Electron 테스트 64개, Rust 테스트 10개, TypeScript 및 Clippy 검사 통과. 네이티브 release 빌드는 개발 인증서로 서명한다.
